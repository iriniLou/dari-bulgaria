# Дари летит в Болгарию ✈️🇧🇬

Игра-воспоминание для Дари к проводам 17 октября: наша история, фонари, Главвино и интерактивная карта Болгарии.

## Что внутри

| Пункт | Что там |
|---|---|
| 1. Как всё началось | История знакомства на выставке «Россия» + анимированная первая переписка с угадайкой |
| 2. Фонарный пилон | Игра на точность: поймай момент — откроется фото трюка |
| 3. Мемори и мультик | Мемори из фото, стоп-моушен из 15 кадров (скорость, бумеранг), галерея |
| 4. Досье: Дари | Квиз про нас и генератор комплиментов |
| 5. Карта Болгарии | 46 мест (28 малоизвестных), фильтры, «хочу поехать», мои отметки 📌, нарисованная карта |
| 6. Болгарская академия | Тренажёр «кивок = нет», ложные друзья, разговорник с озвучкой, факты |
| 7. Собери чемодан | Что взять в новую жизнь |
| 8. Экзамен на болгарку | Квиз о Болгарии |
| Финал | Открывается после 8 штампов: письмо и список мест для карты на стене |

Прогресс сохраняется в браузере. Музыка — кнопки справа вверху (пауза, без звука, громкость).

## Как поправить

```
index.html   ← разметка
data.js      ← ВСЕ ТЕКСТЫ: подписи к фото, вопросы, места на карте, письмо, подпись (GAME.fromName)
app.js       ← логика
style.css    ← оформление (цвета — в начале файла)
img/photos/  ← фото 01–15 (порядок = порядок кадров мультика)
img/chat.png ← скриншот первой переписки
img/map-drawing.webp ← нарисованная карта
audio/music.mp3      ← фоновая музыка
```

Проверить локально: `python -m http.server` в этой папке и открыть http://localhost:8000 (или просто двойной клик по `index.html`).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `dari-bulgaria`) и загрузите туда содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту-две игра будет по адресу `https://<логин>.github.io/dari-bulgaria/`.

Репозиторий с фото будет публичным, если не выбрать Private (для Pages на бесплатном аккаунте нужен публичный).
